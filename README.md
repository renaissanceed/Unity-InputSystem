# Unity-InputSystem

> Unity 新输入系统（Input System）学习工程 ｜ Unity 2022.3.62f1 ｜ 8 个 Lesson + 1 个改键小项目

从「直接读键」到「用 InputAction 资产驱动」，逐层验证新输入系统的核心概念：Action、Binding、Control Scheme、Action Map、PlayerInput、PlayerInputManager。最后用一个小项目把**运行时改键**跑通。

## 为什么要用新输入系统

旧的 `Input.GetKey` 存在的问题：键位硬编码、多设备适配麻烦、无法做键位重绑定、多人输入需要自己分发。新输入系统把「玩家意图（Action）」和「物理按键（Binding）」解耦，改键只改 Binding，不动逻辑代码。

## 核心实现：运行时改键

这是本工程最有价值的部分，实现在 `Assets/Scripts/实践小项目_改键/`。

### 思路

`.inputactions` 本质是一个 JSON 文件。与其在运行时操作 `InputActionAsset` 的对象图，不如**把 JSON 当模板，做字符串占位符替换，再反序列化回对象**——实现简单且不易破坏结构。

```csharp
public InputActionAsset GetActionAsset()
{
    string str = jsonStr.Replace("<up>",    infos.up);
    str = str.Replace("<jump>",  infos.jump);
    str = str.Replace("<left>",  infos.left);
    str = str.Replace("<right>", infos.right);
    str = str.Replace("<fire>",  infos.fire);
    str = str.Replace("<down>",  infos.down);

    return InputActionAsset.FromJson(str);   // 关键：从 JSON 重建输入资产
}
```

配套结构：

| 文件 | 职责 |
|---|---|
| `InputInfo.cs` | 六个可改键位的字段（上/下/左/右/跳/开火） |
| `DataManager.cs` | 单例，读 `Resources/Les` 的 JSON 模板，替换后 `FromJson` |
| `ChangeInputPanel.cs` | 改键界面，监听「按下任意键」并把绑定路径写回 `InputInfo` |
| `PlayerLes.cs` | 玩家控制器，从 `DataManager` 取当前 ActionAsset 并绑定回调 |

改键流程：进入改键面板 → 点击某个功能项 → 监听 `Keyboard.current.anyKey` → 取得按下的 `KeyControl` → 转成绑定路径（如 `<Keyboard>/space`）→ 更新 `InputInfo` → 重新 `FromJson` 生成资产 → 玩家控制器换用新资产。

## 说明

- 工程需安装 `com.unity.inputsystem` 包，并将 Player Settings 中的 Active Input Handling 设为 `Input System Package (New)` 或 `Both`；
- 手柄相关 Lesson 需要接入实际手柄设备才能验证轴值与扳机键；
- 改键小项目使用 JSON 模板替换方案，优点是实现简单，缺点是新增 Action 时需要同步修改模板与 `InputInfo` 字段。
